# JKLU Papers

Study material and examination resources for Semester 1 at JKLU. This repository keeps lecture notes, reference books, syllabi, solved problem sets, practice sheets, and mid-semester papers together in one place.

## Contents

| Subject | Available material |
| --- | --- |
| [Applied Physics](SEM-1/APPLIED%20PHYSICS) | Course description, mechanics book, introductory notes, mathematics review, conversion factors, scalars and vectors, and mid-semester paper images |
| [Calculus](SEM-1/CALCULUS) | Syllabus, compressed reference book, lecture notes, partial derivatives and contours material, solved problems, and mid-semester paper images |
| [FOCP](SEM-1/FOCP) | Communication notes covering definitions, basics, models, barriers, the Seven C's, instructions, and Chapter 1 material |
| [Fundamentals of EE](SEM-1/FUNDAMENTALS%20OF%20EE) | Syllabus, circuit-analysis notes, KVL/KCL, nodal and mesh analysis, practice sheets, Micro-Cap work, and mid-semester paper images |
| [IKS](SEM-1/IKS) | Indian Knowledge Systems course description |

## File Organization

-  lecture and reference material in the subject's `class notes` folder.
-  examination scans or images in the subject's `mid sem` or `mid sem papers` folder.
-  exercises and worked practice in `practice questions`.
- Keep each file inside its relevant subject folder and use a descriptive filename.

## Notes

- This is a student-maintained collection and may grow throughout the semester.

- PDF and image files are stored as study resources; always verify the latest syllabus or course instructions with the university.
